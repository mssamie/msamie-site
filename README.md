# msamie.com

Source for [Mohammad Sadegh Samie's academic website](https://msamie.com/).

The site is built with Hugo Blox and deployed through GitHub Pages. Public research
content is limited to peer-reviewed work and material cleared for public sharing.

## Local development

1. Install the Hugo Extended version specified in `hugoblox.yaml`.
2. Install the Node dependencies with `pnpm install`.
3. Run `pnpm dev` for a local preview.
4. Run `pnpm build` for a production build.
